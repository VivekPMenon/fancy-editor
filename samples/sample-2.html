3. Alignment, Indentation and Spacing

This section varies paragraph-level properties only. The run properties stay constant, so any difference your parser reports should come from the paragraph formatting layer.

This paragraph has two sentences and is left aligned. Left alignment is the default for body text in this document.

This paragraph has two sentences and is centered. Centering is common for titles and pull quotes.

This paragraph has two sentences and is right aligned. Right alignment is often used for dates and signature blocks.

This paragraph has two sentences and is justified, so both the left and right edges line up cleanly against the margins. Justification changes the inter-word spacing on every line except the last one.

This paragraph has a first-line indent of half an inch, which is set through the paragraph format rather than by typing a tab character at the start of the line.

This paragraph is indented one inch from the left margin and half an inch from the right margin, producing a block-quote effect without using the Quote style.

This paragraph uses a hanging indent, so the first line starts at the margin and every subsequent line is indented. Hanging indents are typical in bibliographies and definition lists.

This paragraph uses double line spacing. It should be visibly taller than the single-spaced paragraphs around it.

This paragraph uses 1.5 line spacing with twelve points of space before and eighteen points of space after.

This paragraph is set to keep with the next paragraph and to keep its own lines together, which affects pagination only.
